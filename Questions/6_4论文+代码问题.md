## 问题1：`NameError: name 'CBAM' is not defined`

我的问题，导出的时候不小心删了一个cell，这是 Python **类定义顺序**问题。`ResidualCBAMBlock` 在 `__init__` 里调用了 `CBAM(out_channels)`，但 Python 解释器在执行这行时，`CBAM` 类还没有被定义或者定义在了另一个 cell 里还没运行。

**解决方法**：确保定义顺序严格按照依赖关系从上到下：

```python
# ── 必须按这个顺序定义，缺一不可 ──────────────────────────────

# 第1步：最底层组件
class ChannelAttention(nn.Module):
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.avg_pool = nn.AdaptiveAvgPool2d(1)
        self.max_pool = nn.AdaptiveMaxPool2d(1)
        self.fc = nn.Sequential(
            nn.Linear(channels, max(1, channels // reduction)),
            nn.ReLU(),
            nn.Linear(max(1, channels // reduction), channels),
        )
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        B, C, _, _ = x.shape
        avg = self.fc(self.avg_pool(x).view(B, C))
        mx  = self.fc(self.max_pool(x).view(B, C))
        w   = self.sigmoid(avg + mx).view(B, C, 1, 1)
        return x * w


# 第2步：依赖 ChannelAttention
class SpatialAttention(nn.Module):
    def __init__(self, kernel_size=7):
        super().__init__()
        self.conv = nn.Conv2d(2, 1, kernel_size=kernel_size,
                              padding=kernel_size // 2, bias=False)
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        avg = x.mean(dim=1, keepdim=True)
        mx, _ = x.max(dim=1, keepdim=True)
        w = self.sigmoid(self.conv(torch.cat([avg, mx], dim=1)))
        return x * w


# 第3步：依赖 ChannelAttention + SpatialAttention
class CBAM(nn.Module):
    def __init__(self, channels, reduction=16):
        super().__init__()
        self.ca = ChannelAttention(channels, reduction)
        self.sa = SpatialAttention()

    def forward(self, x):
        return self.sa(self.ca(x))


# 第4步：依赖 CBAM  ← 这个必须在 CBAM 之后
class ResidualCBAMBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3,
                      stride=stride, padding=1, bias=False),
            nn.BatchNorm2d(out_channels),
            nn.ReLU(),
        )
        self.cbam = CBAM(out_channels)   # ← 此时 CBAM 已定义，不会报错
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, 1,
                          stride=stride, bias=False),
                nn.BatchNorm2d(out_channels),
            )

    def forward(self, x):
        out = self.cbam(self.conv(x))
        return F.relu(out + self.shortcut(x))


# 第5步：最后实例化模型
model = BCAMNet().to(DEVICE)
```

**最常见的错误场景**是把这五个类分散在不同 cell 里，但没有按顺序运行，或者运行了 `BCAMNet` 的 cell 但跳过了中间某个定义 cell。建议把这四个类**放在同一个 cell 里**，一起运行。

## 问题2 公式问题：
---

### 一、 公式（6）存在的问题：$\lambda$ 错用与分子符号写反

$$P_D = Q\left( \frac{\lambda - \tau}{\frac{\sigma_w^2}{N}} \right) \quad (6)$$

#### 1. 错误一：$\lambda$ 根本不是均值（物理意义与量纲错误）
* **物理意义不符**：论文在 Eq (3) 中定义的测试统计量 $T$ 是**平均能量**，其单位是功率/能量。但在 Eq (5) 后面，论文写道：“$\lambda = \frac{N\gamma}{2}$ 是非中心参数”。
* **量纲（单位）冲突**：$\lambda$ 是非中心卡方分布的非中心参量，它是**无量纲**的。而门限 $\tau$ 的单位是功率（例如 $\sigma_w^2$）。在物理上，你**绝不能把一个无量纲的数 $\lambda$ 与一个带功率单位的门限 $\tau$ 直接相减**。
* **正确的均值**：根据中心极限定理（CLT），在 $H_1$ 假设下，平均能量 $T$ 的实际数学均值应该是：
  $$E[T|H_1] = \sigma_w^2 + \sigma_s^2 = \sigma_w^2(1 + \gamma) \quad (\text{其中 }\gamma\text{ 为 SNR})$$

#### 2. 错误二：分子符号写反了（正负逻辑错误）
根据标准高斯尾概率 $Q(x)$ 函数的定义：
* $x$ 为正数且很大时，$Q(x) \approx 0$（虚警率或漏检率很低）；
* $x$ 为负数且很小时，$Q(x) \approx 1$（检测概率很高）。

在 $H_1$ 假设下，我们希望检测概率 $P_D$ 接近于 1。因为信号存在时的平均能量 $E[T|H_1]$ 明显大于设定门限 $\tau$（即 $E[T|H_1] > \tau$），所以正确的公式分子部分应当是：
$$\tau - E[T|H_1] \quad (\text{这是一个负数，带入 } Q \text{ 才能使 } P_D \approx 1)$$

如果像论文中写成 $\text{均值} - \tau$（即 $\lambda - \tau$），由于信号能量大于门限，分子会是一个正数，导致算出来的检测概率 $P_D = Q(\text{正数}) \approx 0$。这意味着**信号越强，检测概率反而越接近 0**，这显然完全违背了物理事实。

---

### 二、 公式（7）存在的问题：分子符号正确，但分母漏掉根号

$$PFA = Q\left( \frac{\tau - \sigma_w^2}{\frac{\sigma_w^2}{N}} \right) \quad (7)$$

#### 1. 关于分子符号：其实没有写反
* 虚警概率 $PFA$ 是指“无信号时，平均能量却意外超过门限 $\tau$ 的概率”。
* 为了保证虚警率极低，我们设定的门限 $\tau$ 必须大于纯噪声功率 $\sigma_w^2$（即 $\tau > \sigma_w^2$）。
* 因此，分子 $\tau - \sigma_w^2$ 是一个**正数**。
* 这样虚警概率 $PFA = Q(\text{正数}) \approx 0$，是一个极小值。这在逻辑上是完全正确的，所以**公式（7）的分子符号没有写反**。

#### 2. 错误三：公式（7）和（6）的分母都漏掉了根号
除了分子的问题外，这两个公式的分母还存在一个极其低级的数学错误：
根据论文中的 Eq (4)，在 $H_0$ 条件下，测试统计量服从卡方分布 $T \sim \frac{\sigma_w^2}{2N} \chi^2_{2N}$：
* $T$ 的数学均值为 $\sigma_w^2$。
* $T$ 的方差为 $Var(T) = \frac{\sigma_w^4}{N}$。
* 因此，根据中心极限定理作高斯近似时，分母所采用的标准差（Standard Deviation）应当是方差开根号，即：
  $$\sigma_0 = \sqrt{Var(T)} = \frac{\sigma_w^2}{\sqrt{N}}$$

然而，论文在公式（6）和（7）中，分母位置都写成了：
$$\frac{\sigma_w^2}{N}$$
这显然是**漏掉了对样本数 $N$ 开放（即漏掉了 $\sqrt{N}$）**。

---

### 总结：正确的教科书级公式应当为

对于平均能量检测，在复高斯白噪声下，基于中心极限定理（CLT）近似的正确公式为：

$$\text{虚警概率：} P_{FA} = Q\left( \frac{\tau - \sigma_w^2}{\frac{\sigma_w^2}{\sqrt{N}}} \right)$$

$$\text{检测概率：} P_D = Q\left( \frac{\tau - \sigma_w^2(1 + \gamma)}{\frac{\sigma_w^2(1 + \gamma)}{\sqrt{N}}} \right)$$
