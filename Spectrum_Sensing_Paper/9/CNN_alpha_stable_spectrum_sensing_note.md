# Spectrum Sensing for Symmetric α-Stable Noise Model With CNNs 阅读记录

> 论文：**Spectrum Sensing for Symmetric α-Stable Noise Model With Convolutional Neural Networks**  
> 期刊：IEEE Transactions on Communications, 2021  
> 阅读重点：频谱感知如何被建模为人工智能问题。网络结构部分只保留必要信息。

## 1. 这篇论文主要解决什么问题

这篇论文研究的是认知无线电中的频谱感知问题。简单说，就是次用户（SU）在使用频谱之前，需要判断主用户（PU）现在有没有占用该频段：

- 如果 PU 不存在，说明频段空闲，SU 可以接入；
- 如果 PU 存在，SU 不能接入，否则会干扰 PU 通信。

传统频谱感知方法常常假设接收噪声是高斯噪声。但实际环境中，噪声不一定这么“规整”。比如电机、电弧、闪电、汽车点火、荧光灯等都会带来脉冲噪声。这类噪声具有重尾特性，偶尔会出现很大的突发干扰。  
因此，本文没有只用高斯噪声，而是采用 **对称 α 稳定分布（SαS）** 来统一描述从高斯噪声到严重脉冲噪声的情况。

论文核心问题可以概括为：

> 在噪声模型不稳定、可能存在强脉冲噪声的情况下，如何更可靠地判断 PU 是否存在？

## 2. 频谱感知的原始信号模型

论文考虑的是一个比较基础的 SISO 场景，即 PU 和 SU 都是单天线。SU 接收到的复基带信号可以写成：

```math
r[n] = h s[n] + w[n], \quad n = 1,2,\cdots,N
```

其中：

- `r[n]`：SU 接收到的第 n 个采样点；
- `s[n]`：PU 发射信号；
- `h`：信道系数；
- `w[n]`：接收噪声；
- `N`：一个感知周期内的采样点数。

由于接收信号是复数信号，可以拆成 I/Q 两路：

```math
w[n] = w_I[n] + j w_Q[n]
```

论文假设 I 路和 Q 路噪声都服从 SαS 分布：

```math
w_I[n], w_Q[n] \sim S\alpha S(\mu,\alpha,\gamma)
```

这里最重要的是参数 `α`：

- `α = 2` 时，对应普通高斯噪声；
- `α = 1` 时，对应柯西噪声，重尾最明显，脉冲性最强；
- `1 < α < 2` 时，表示介于高斯噪声和强脉冲噪声之间的情况。

所以，本文其实是把“噪声不一定是高斯”的问题显式建模进来了。

## 3. 传统频谱感知：先写成二元假设检验

频谱感知最传统的建模方式是二元假设检验：

```math
\begin{cases}
H_0: r[n] = w[n], \quad \text{PU 不存在} \\
H_1: r[n] = h s[n] + w[n], \quad \text{PU 存在}
\end{cases}
```

然后构造一个检测统计量 `f(r)`，与阈值 `η` 比较：

```math
f(r) \mathop{\gtrless}_{H_0}^{H_1} \eta
```

也就是说：

- 如果 `f(r) > η`，判定为 `H1`，即 PU 存在；
- 如果 `f(r) < η`，判定为 `H0`，即 PU 不存在。

评价指标主要是：

```math
P_d = Pr\{f(r)>\eta | H_1\}
```

```math
P_{fa} = Pr\{f(r)>\eta | H_0\}
```

其中 `Pd` 是检测概率，越高越好；`Pfa` 是虚警概率，通常要控制在固定水平，比如本文中常用 `Pfa = 0.01`。

## 4. 为什么传统方法不够好

论文先推了 LRT、Wald test 和 Rao test 等传统检测方法。这里不需要把全部推导细节看完，重点是看它们为什么会失效。

### 4.1 高斯噪声下，LRT 会退化成能量检测

当 `α = 2` 时，SαS 噪声就是高斯噪声。此时 LRT 最后可以化简成：

```math
f(r)=\|r\|^2
```

这就是常见的 **Energy Detection，能量检测**。

它的含义很直观：如果接收信号能量明显变大，就认为 PU 存在。

但问题在于，能量检测默认噪声比较稳定。如果噪声是重尾脉冲噪声，即使没有 PU，也可能突然出现很大的噪声尖峰，使接收能量变大，导致误判。

### 4.2 柯西噪声下，可以推柯西检测器，但泛化性仍然有限

当 `α = 1` 时，噪声服从柯西分布。论文推导得到的检测统计量为：

```math
f(r)=\sum_{n=1}^{N}
\log \left( 
\left(r_I[n]^2+\gamma^2\right)
\left(r_Q[n]^2+\gamma^2\right)
\right)
```

这个检测器适合柯西噪声，但它仍然是模型驱动的。换句话说，它假设噪声模型就是某一种特定形式。  
实际情况中，`α` 可能不是 1，也不是 2，而是 1.25、1.5、1.75 这样的中间值。此时 LRT 往往没有简洁的闭式表达式，每换一个环境都重新推检测器也不现实。

所以这篇论文提出 CNN 的动机很清楚：

> 与其为每一种噪声模型单独设计检测统计量，不如直接让模型从接收采样中学习“PU 存在”和“PU 不存在”的差别。

## 5. 如何建模成人工智能问题

这是本文最值得关注的部分。

传统方法是：

```text
接收信号 → 手工构造检测统计量 → 与阈值比较 → 判断 H0/H1
```

本文改成：

```text
接收信号序列 → CNN 分类器 → 输出 PU 存在概率 → 判断 H0/H1
```

也就是说，频谱感知被建模为一个 **二分类问题**。

### 5.1 输入是什么

输入不是频谱图，也不是协方差矩阵，也不是 STFT 图像，而是一个感知周期内的原始接收复基带采样：

```math
r = [r[1],r[2],\cdots,r[N]]^T
```

因为 `r[n]` 是复数，所以实际输入时把 I 路和 Q 路分开，类似于把一个信号拆成两个通道：

```text
I 路序列：r_I[1], r_I[2], ..., r_I[N]
Q 路序列：r_Q[1], r_Q[2], ..., r_Q[N]
```

这一点比较重要。很多 CNN 频谱感知工作会先把数据变成二维图像或协方差矩阵，但本文强调的是 **直接使用原始采样点，不做复杂预处理**。

### 5.2 标签是什么

每个样本的标签就是当前频段状态：

```math
y_k =
\begin{cases}
0, & H_0，PU 不存在 \\
1, & H_1，PU 存在
\end{cases}
```

因此，一个训练样本可以写成：

```math
(r_k,y_k)
```

其中 `r_k` 是第 k 个接收信号序列，`y_k` 是它对应的频谱状态。

### 5.3 模型学的是什么

CNN 学的是一个映射关系：

```math
f_\theta(r_k) \rightarrow [0,1]
```

可以理解为模型输出“PU 存在”的概率。输出越接近 1，越倾向于判定为 `H1`；输出越接近 0，越倾向于判定为 `H0`。

训练时采用二分类交叉熵损失：

```math
BCE = -\frac{1}{K}\sum_{k=1}^{K}
\left[
y_k \log f(r_k) + (1-y_k)\log(1-f(r_k))
\right]
```

这个公式的意思很直接：

- 如果真实标签是 1，就希望模型输出接近 1；
- 如果真实标签是 0，就希望模型输出接近 0；
- 如果模型输出和真实标签差得远，损失就变大。

从这个角度看，CNN 相当于自动学习一个检测统计量。传统方法中的 `f(r)` 是人工设计的，而这里的 `f_\theta(r)` 是从数据中学出来的。

### 5.4 阈值怎么处理

频谱感知不是只追求分类准确率，还要控制虚警概率 `Pfa`。  
本文提出的方法是通过调整 CNN 最后一层神经元的偏置项，使模型在 `H0` 样本上的虚警概率达到设定要求，比如 `Pfa = 0.01`。

这点和普通分类任务不太一样。普通二分类常用 0.5 做阈值，但频谱感知更关心在固定虚警概率下能获得多高的检测概率。

## 6. 用了什么模态数据

本文使用的数据模态可以概括为：

| 项目 | 内容 |
|---|---|
| 数据类型 | 原始复基带 IQ 采样序列 |
| 输入形式 | 一维序列，I/Q 两路作为两个输入通道 |
| 是否转图像 | 否 |
| 是否做 STFT/CWT | 否 |
| 是否构造协方差矩阵 | 否 |
| 场景 | 单天线 SU，可扩展到多天线 |
| 任务标签 | PU 存在/不存在，即 H1/H0 |

所以这篇论文的模态非常简单：**原始 IQ 时域序列**。  
它的重点不是做多模态融合，而是验证在复杂噪声下，直接用一维 CNN 从原始采样中学习检测规则是否更稳健。

## 7. 采用了什么模型

本文使用的是一维 CNN 检测器。网络结构不用细看，知道大致流程即可：

```text
原始 IQ 序列
→ 1D 卷积层
→ 最大池化
→ 1D 卷积层
→ 最大池化
→ 1D 卷积层
→ 最大池化
→ 全连接层
→ Sigmoid 输出
```

论文中给出的主要结构是：

- 3 个一维卷积层；
- 每个卷积层后接最大池化；
- 后面接 3 个全连接层；
- 最后一层用 Sigmoid 输出 PU 存在概率；
- 训练损失为 BCE；
- 优化方法采用 Adam 和反向传播。

这里可以略读，因为本文的重点不是提出很复杂的新网络，而是说明：**把原始接收信号直接交给 CNN，可以避免对具体噪声模型的强依赖。**

## 8. 实验数据集怎么构造

本文没有使用公开真实数据集，而是基于通信模型仿真生成数据。

主要设置如下：

| 项目 | 设置 |
|---|---|
| 接收端 | 单天线 SU |
| 一个感知周期采样数 | N = 100，部分实验也使用 N = 50、500 |
| PU 调制方式 | QPSK |
| 信道 | 平坦慢衰落信道 |
| 噪声模型 | 复 SαS 噪声 |
| α 取值 | {1, 1.25, 1.5, 1.75, 2} |
| γ | 0.5 |
| 虚警概率 | Pfa = 0.01 |
| H0 样本 | 8 × 10^4 个噪声信号 |
| H1 样本 | 2.5 × 10^4 个含 PU 信号的样本 |
| 每个 α 下总样本量 | 10.5 × 10^4 |
| 训练轮数 | 20 epochs |

其中：

- `α = 2` 表示高斯噪声；
- `α = 1.5` 表示中等脉冲噪声；
- `α = 1` 表示严重脉冲噪声。

实验对比方法包括：

- ED：能量检测；
- CD：柯西检测；
- FLOM：分数低阶矩检测；
- RaoC；
- ANN；
- SAE；
- 本文提出的 CNN。

## 9. 实验结果怎么看

### 9.1 高斯噪声下

当 `α = 2` 时，噪声是高斯噪声。这个时候 ED 本来就是很强的基准方法，因为它刚好符合高斯噪声假设。

实验结果显示：

- ED 表现最好；
- ANN 因为使用能量特征，表现也接近 ED；
- 本文 CNN 的性能接近 ED；
- CD、FLOM、SAE 等方法相对差一些。

这说明在理想高斯噪声下，传统能量检测并不弱，CNN 的优势不明显。

### 9.2 中等脉冲噪声下

当 `α = 1.5` 时，噪声开始呈现明显重尾特性。此时传统能量类方法容易被脉冲噪声误导。

实验结果显示：

- 本文 CNN 的检测概率最高；
- 在 GSNR = 0 dB 时，CNN 的 `Pd` 约为 0.5；
- ED 和 ANN 性能明显下降；
- CD 和 FLOM 比 ED 稳一些，但仍不如 CNN。

这里能看出 CNN 的优势：它不是只看总能量，而是能从原始序列中学习到更稳定的判别特征。

### 9.3 严重脉冲噪声下

当 `α = 1` 时，噪声退化为柯西噪声，脉冲性最强。这个场景最能体现方法的鲁棒性。

实验结果显示：

- CNN 仍然保持相对较好的检测性能；
- ED 和 ANN 几乎失效；
- 即使是专门为柯西噪声推导的 CD 和 RaoC，也不如 CNN 稳定；
- RaoC 在高 GSNR 下甚至出现不符合直觉的下降趋势，因为它会把某些高幅值样本当成噪声。

所以本文最主要的实验结论是：

> 噪声越偏离高斯分布，CNN 相比传统模型驱动检测器的优势越明显。

### 9.4 参数失配实验

实际场景中，SU 往往不知道真实的 `α` 和 `γ`。如果训练时和测试时的噪声参数不一致，模型是否还能用，是一个关键问题。

论文做了参数失配实验。例如：

- 训练数据使用 `(α, γ) = (1.5, 0.5)`；
- 测试数据使用有 10% 偏差的参数；
- 还测试了更严重的 30% 参数失配。

结果显示：

- CNN 对参数失配最稳健；
- 在 10% 失配、`N=50` 的情况下，为达到 `Pd = 0.65`，CNN 需要约 5.6 dB，而 CD 需要约 8.05 dB；
- 在 30% 失配下，CNN 仍能保持接近其他检测器无失配时的表现。

这部分说明 CNN 的优势不仅在于检测性能，更在于它不需要非常精确地知道噪声分布参数。

### 9.5 复杂度问题

CNN 的缺点也很明显：计算复杂度更高。

论文统计了乘法次数：

- ANN：约 221 次；
- SAE：约 25050 次；
- CNN：约 4172864 次。

CNN 的计算量主要来自多个卷积层和较多卷积滤波器。作者也讨论了减少滤波器数量的方法，例如把滤波器数从 128 降到 64、16、8，可以明显降低复杂度，但整体上 CNN 仍比传统检测器更重。

所以这篇论文的结论不是“CNN 完全替代传统方法”，而是：

> 如果场景接近高斯噪声，传统 ED 足够简单有效；如果场景存在明显脉冲噪声或噪声参数不确定，CNN 更稳健，但需要付出更高计算量。

## 10. 一句话总结这篇论文

这篇论文把频谱感知从“基于噪声模型推检测统计量”的传统假设检验问题，改写成“输入原始 IQ 采样序列、输出 PU 是否存在”的二分类问题。它没有把信号转成图像，也没有依赖协方差矩阵，而是直接用一维 CNN 从原始采样中学习检测规则。实验表明，在高斯噪声下 CNN 接近能量检测；在 α 稳定分布产生的脉冲噪声和参数失配条件下，CNN 比 ED、CD、FLOM、ANN、SAE 等方法更稳健，但代价是计算复杂度更高。

## 11. 可放进论文阅读汇报的简版

本文面向认知无线电中的频谱感知问题，考虑了比高斯噪声更一般的对称 α 稳定噪声模型。传统方法将频谱感知建模为二元假设检验，并根据噪声分布推导检测统计量，例如高斯噪声下的能量检测和柯西噪声下的柯西检测器。但当噪声分布在不同环境中变化时，模型驱动方法对参数和分布假设较敏感，泛化能力有限。

因此，论文将频谱感知进一步建模为人工智能中的二分类问题：以一个感知周期内的原始 IQ 接收采样序列作为输入，以 PU 存在或不存在作为标签，训练一维 CNN 输出 PU 存在概率。该方法不需要将信号转换为时频图或协方差矩阵，也不依赖手工设计统计量。实验采用仿真生成的 QPSK 信号和 SαS 噪声数据集，对比 ED、CD、FLOM、RaoC、ANN、SAE 等方法。结果表明，在高斯噪声下 CNN 接近能量检测；在脉冲噪声和参数失配条件下，CNN 具有更好的检测鲁棒性。不过，由于网络包含多层卷积和全连接结构，其计算复杂度高于传统检测器。
