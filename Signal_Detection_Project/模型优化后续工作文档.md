## 1. 问题诊断总览

根据当前实验结果，主要存在以下问题：

| 问题 | 现象 | 根因 |
|---|---|---|
| **过拟合** | Ep3后训练Loss持续下降，验证Loss上升 | `scheduler.step()` 被调用两次，LR下降过快；正则化不足 |
| **低SNR检测差** | 测试集1 Pd=72%（训练外SNR） | 训练数据低SNR样本不足；模型未见过极端SNR |
| **Pd偏低** | 默认阈值0.5导致大量漏检 | 应使用NP准则找最优阈值 |
| **模态权重固定** | BCA门控值训练后变化不大 | 门控初始化为0，梯度流弱 |

## 2. Bug修复（必做）

### 2.1 `scheduler.step()` 重复调用

**问题位置**：Cell 9 训练循环

**原因**：循环内 `scheduler.step(vl_l)` 被调用了两次，等价于把 `patience=3` 压缩成 `patience=1.5`，导致Epoch 3就触发LR下降，模型还没学好就被迫进入精细调整阶段。

**修复方法**：删除第一次调用，只保留打印LR变化那一次。

```python
# ❌ 原代码（有Bug）
for ep in range(1, NUM_EPOCHS + 1):
    tr_l, tr_a = run_epoch(...)
    vl_l, vl_a = run_epoch(...)
    scheduler.step(vl_l)          # 第1次 ← 删掉这行

    ...
    old_lr = optimizer.param_groups[0]['lr']
    scheduler.step(vl_l)          # 第2次（保留）
    new_lr = optimizer.param_groups[0]['lr']

# ✅ 修复后
for ep in range(1, NUM_EPOCHS + 1):
    tr_l, tr_a = run_epoch(...)
    vl_l, vl_a = run_epoch(...)
    # 只调用一次
    old_lr = optimizer.param_groups[0]['lr']
    scheduler.step(vl_l)
    new_lr = optimizer.param_groups[0]['lr']
    if new_lr < old_lr:
        print(f'   ⚠️  LR: {old_lr:.2e} → {new_lr:.2e}')
```

**添加位置**：直接替换 Cell 9 的训练循环部分。

## 3. 训练策略优化

### 3.1 早停（Early Stopping）+ patience调整

**修改位置**：Cell 9，替换整个训练循环。

```python
# ============================================================
# Cell 9（替换版）: 训练循环 + 早停 + 修复scheduler

criterion = nn.CrossEntropyLoss(label_smoothing=0.05)  # 加入标签平滑，见第4节

    {'params': model.time_branch.parameters(),  'lr': 1e-3},

    optimizer, mode='min', factor=0.5, patience=3)

NUM_EPOCHS  = 50    # 上限放宽，依靠早停控制实际轮次
EARLY_STOP  = 10    # 连续10个epoch无改善则停止
no_improve  = 0

best_state  = None

    tr_l, tr_a = run_epoch(model, train_loader, criterion, optimizer, DEVICE, True)
    vl_l, vl_a = run_epoch(model, val_loader,   criterion, optimizer, DEVICE, False)

    history['tr_loss'].append(tr_l);  history['val_loss'].append(vl_l)
    history['tr_acc'].append(tr_a);   history['val_acc'].append(vl_a)

    star = ''
    if vl_l < best_val:
        best_val   = vl_l
        best_state = {k: v.detach().cpu().clone()
                      for k, v in model.state_dict().items()}
        star       = ' ⭐'
        no_improve = 0
    else:
        no_improve += 1

    scheduler.step(vl_l)
    new_lr = optimizer.param_groups[0]['lr']

        print(f'\n⛔ Early Stop: 连续{EARLY_STOP}个epoch验证损失无改善，停止训练')
```

## 4. 正则化强化

### 4.1 标签平滑（Label Smoothing）

**原理**：将 one-hot 标签从 `[0, 1]` 软化为 `[ε/K, 1-ε+ε/K]`，防止模型对训练集标签过度自信。

$$\tilde{y}_k = (1 - \varepsilon) y_k + \frac{\varepsilon}{K}$$

**代码**：只需修改 `criterion` 的一行，`nn.CrossEntropyLoss` 已内置支持：

```python
# 在 Cell 9 顶部替换 criterion 定义

# label_smoothing=0.05 表示 ε=5%，是二分类的推荐值
# 如果过拟合严重可以调到 0.1
```

### 4.2 Dropout 增强 + DropPath

当前模型只在 MLP 层有 Dropout，可以在 BiLSTM 输出和 BCA 之间加一个额外的 Dropout：

```python
def forward(self, x_time, x_img):

    # 在BCA之前加Dropout（防止两个分支的特征过度适应训练集）
    f_time = F.dropout(f_time, p=0.1, training=self.training)
    f_img  = F.dropout(f_img,  p=0.1, training=self.training)
```

### 4.3 MixUp 数据增强

**原理**：对两个训练样本做线性插值，生成虚拟样本，显著缓解过拟合，对低SNR样本尤其有效（在噪声和信号之间插值，增加边界样本）：

$$\tilde{x} = \lambda x_i + (1-\lambda) x_j, \quad \lambda \sim \text{Beta}(\alpha, \alpha)$$

```python
# 在 Cell 9 的 run_epoch 函数内部，train=True 分支中添加
def mixup_data(x_time, x_img, y, alpha=0.2):
    """对时域和图像双模态数据同时做MixUp。"""
    if alpha <= 0:
        return x_time, x_img, y, y, 1.0
    lam = np.random.beta(alpha, alpha)
    B   = x_time.size(0)
    idx = torch.randperm(B, device=x_time.device)

    x_time_mix = lam * x_time + (1 - lam) * x_time[idx]
    x_img_mix  = lam * x_img  + (1 - lam) * x_img[idx]
    y_a, y_b   = y, y[idx]
    return x_time_mix, x_img_mix, y_a, y_b, lam


def mixup_criterion(criterion, logits, y_a, y_b, lam):
    """MixUp对应的混合损失。"""
    return lam * criterion(logits, y_a) + (1 - lam) * criterion(logits, y_b)


# 在 run_epoch 的训练循环中替换损失计算部分：
def run_epoch(model, loader, criterion, optimizer, device, train=True, use_mixup=True):
    model.train() if train else model.eval()
    total_loss = total_correct = total_n = 0
    ctx = torch.enable_grad() if train else torch.no_grad()

    with ctx:
        for x_time, x_img, yb in loader:
            x_time = x_time.to(device); x_img = x_img.to(device); yb = yb.to(device)
            if train: optimizer.zero_grad()

            if train and use_mixup:
                x_time, x_img, y_a, y_b, lam = mixup_data(x_time, x_img, yb, alpha=0.2)
                logits = model(x_time, x_img)
                loss   = mixup_criterion(criterion, logits, y_a, y_b, lam)
                # MixUp下准确率用原始标签计算
                pred   = logits.argmax(1)
                total_correct += (lam * (pred == y_a).float() +
                                  (1-lam) * (pred == y_b).float()).sum().item()
            else:
                logits = model(x_time, x_img)
                loss   = criterion(logits, yb)
                total_correct += (logits.argmax(1) == yb).sum().item()

            if train:
                loss.backward()
                nn.utils.clip_grad_norm_(model.parameters(), 1.0)
                optimizer.step()

            total_loss += loss.item() * len(yb)
            total_n    += len(yb)

    return total_loss / total_n, total_correct / total_n
```

**添加位置**：在 Cell 9 的 `run_epoch` 函数之前插入 `mixup_data` 和 `mixup_criterion`，然后替换 `run_epoch` 函数。

## 5. 网络结构升级

### 5.1 方案A：ResNet18 → ResNet50（推荐优先尝试）

**代价**：参数量从 ~11M 增加到 ~23M，T4 GPU 完全可以承受。
**收益**：ResNet50 使用 Bottleneck 结构，特征提取能力明显强于 ResNet18，尤其是对8种模态图像的细节特征。

```python
# 在 Cell 8 的 ResNet18Branch 类中修改 backbone
class ResNet50Branch(nn.Module):
    """
    升级版：ResNet50 替换 ResNet18。
    Bottleneck 结构的深度特征提取能力更强。
    输入  x_img: (B, 8, 32, 32)
    输出  feat : (B, emb_dim)
    """
    def __init__(self, in_channels=8, emb_dim=256, dropout=0.3, pretrained=True):
        super().__init__()
        weights  = models.ResNet50_Weights.IMAGENET1K_V2 if pretrained else None
        backbone = models.resnet50(weights=weights)

        # 替换 conv1: 3通道 → 8通道
        old = backbone.conv1
        backbone.conv1 = nn.Conv2d(
            in_channels, old.out_channels,
            kernel_size=old.kernel_size, stride=old.stride,
            padding=old.padding, bias=False
        )
        with torch.no_grad():
            backbone.conv1.weight[:] = (
                old.weight.mean(dim=1, keepdim=True).expand_as(backbone.conv1.weight)
            )

        self.backbone = nn.Sequential(*list(backbone.children())[:-1])  # 输出 (B,2048,1,1)
        self.proj = nn.Sequential(
            nn.Flatten(),
            nn.Linear(2048, emb_dim),   # ResNet50 输出维度是2048（ResNet18是512）
            nn.ReLU(),
            nn.Dropout(dropout)
        )

    def forward(self, x):
        return self.proj(self.backbone(x))
```

**添加位置**：Cell 8，在 `ResNet18Branch` 类之后紧接着添加 `ResNet50Branch`，然后在 `DualBranchSpectrumNet.__init__` 中将 `ResNet18Branch` 替换为 `ResNet50Branch`：

### 5.2 方案B：加入通道注意力（CBAM/SE）

在 8 个模态通道之间加入**通道注意力**，让模型自动学习哪种模态对当前样本最有用（尤其是低SNR时，部分模态图像质量极差）。

```python
# 在 Cell 8 中，ResNet18/50Branch 类之前添加 ChannelAttention 模块

class ChannelAttention(nn.Module):
    """
    SE（Squeeze-and-Excitation）通道注意力。

    对8个输入模态通道做全局池化后，用MLP学习每个通道的重要性权重。
    低SNR时，PSD/STFT图像质量差，注意力权重会自动降低其影响。

    输入  x: (B, 8, 32, 32)
    输出  x': (B, 8, 32, 32)  通道加权后的图像
    """
    def __init__(self, in_channels=8, reduction=2):
        super().__init__()
        self.avg_pool = nn.AdaptiveAvgPool2d(1)
        self.max_pool = nn.AdaptiveMaxPool2d(1)
        self.fc = nn.Sequential(
            nn.Linear(in_channels, max(1, in_channels // reduction)),
            nn.ReLU(),
            nn.Linear(max(1, in_channels // reduction), in_channels),
        )
        self.sigmoid = nn.Sigmoid()

    def forward(self, x):
        B, C, _, _ = x.shape
        # 平均池化 + 最大池化双路特征
        avg = self.fc(self.avg_pool(x).view(B, C))
        mx  = self.fc(self.max_pool(x).view(B, C))
        # 通道权重
        w   = self.sigmoid(avg + mx).view(B, C, 1, 1)
        return x * w   # 通道加权


# 在 ResNet18Branch（或 ResNet50Branch）的 __init__ 中添加：
class ResNet50Branch(nn.Module):
    def __init__(self, in_channels=8, emb_dim=256, dropout=0.3, pretrained=True):
        super().__init__()
        # ← 新增通道注意力，在送入ResNet之前对8个模态做加权
        self.ch_attn = ChannelAttention(in_channels, reduction=2)

        weights  = models.ResNet50_Weights.IMAGENET1K_V2 if pretrained else None
        backbone = models.resnet50(weights=weights)
        old = backbone.conv1
        backbone.conv1 = nn.Conv2d(
            in_channels, old.out_channels,
            kernel_size=old.kernel_size, stride=old.stride,
            padding=old.padding, bias=False
        )
        with torch.no_grad():
            backbone.conv1.weight[:] = (
                old.weight.mean(dim=1, keepdim=True).expand_as(backbone.conv1.weight)
            )
        self.backbone = nn.Sequential(*list(backbone.children())[:-1])
        self.proj = nn.Sequential(
            nn.Flatten(),
            nn.Linear(2048, emb_dim),
            nn.ReLU(),
            nn.Dropout(dropout)
        )

    def forward(self, x):
        x = self.ch_attn(x)           # ← 先做通道注意力加权
        return self.proj(self.backbone(x))
```

**添加位置**：Cell 8，在 `ResNet18Branch` 之前插入 `ChannelAttention` 类，然后修改图像分支的 `forward` 方法。

### 5.3 方案C：BiLSTM + Multi-head Self-Attention

在 BiLSTM 输出后加一层 Transformer Self-Attention，进一步提取时域的长程依赖：

```python
# 替换 Cell 8 的 BiLSTMBranch 类

class BiLSTMWithAttention(nn.Module):
    """
    BiLSTM + Multi-head Self-Attention 时域分支。

    BiLSTM 捕获局部时序模式，
    Self-Attention 在全局1024步上建立长程依赖关系。
    输入  x: (B, 1024, 4)
    输出  feat: (B, emb_dim)
    """
    def __init__(self, input_size=4, hidden_size=128, emb_dim=256,
                 num_heads=4, dropout=0.3):
        super().__init__()
        self.bilstm = nn.LSTM(
            input_size=input_size, hidden_size=hidden_size,
            num_layers=2, batch_first=True,
            bidirectional=True, dropout=dropout
        )
        lstm_dim = hidden_size * 2  # 双向输出维度

        # Multi-head Self-Attention
        self.attn = nn.MultiheadAttention(
            embed_dim=lstm_dim, num_heads=num_heads,
            dropout=dropout, batch_first=True
        )
        self.norm = nn.LayerNorm(lstm_dim)

        self.proj = nn.Sequential(
            nn.Linear(lstm_dim, emb_dim),
            nn.ReLU(),
            nn.Dropout(dropout)
        )

    def forward(self, x):
        # BiLSTM
        out, _ = self.bilstm(x)           # (B, T, 256)

        # Self-Attention（在T=1024个时间步上做全局注意力）
        attn_out, _ = self.attn(out, out, out)
        out = self.norm(out + attn_out)   # 残差连接

        # Mean Pooling
        feat = out.mean(dim=1)            # (B, 256)
        return self.proj(feat)            # (B, emb_dim)
```

**注意**：1024个时间步的 Self-Attention 计算量为 $O(1024^2)$，在T4上每batch约需200ms，建议配合以下优化：

```python
# 在 forward 中加入局部窗口采样，减少Self-Attention的计算量
# 将1024步降采样到128步后再做Attention
def forward(self, x):
    out, _ = self.bilstm(x)                      # (B, 1024, 256)
    # 每8步取一个：1024 → 128步，大幅降低Attention计算量
    out_sub = out[:, ::8, :]                     # (B, 128, 256)
    attn_out, _ = self.attn(out_sub, out_sub, out_sub)
    out_sub = self.norm(out_sub + attn_out)
    feat = out_sub.mean(dim=1)                   # (B, 256)
    return self.proj(feat)
```

**添加位置**：Cell 8，替换 `BiLSTMBranch` 类，然后在 `DualBranchSpectrumNet.__init__` 中：

```python

```

### 6.2 SNR感知的样本加权（SNR-Aware Weighting）

**原理**：在损失函数中对低SNR样本给更高权重，强迫模型更努力地学习困难样本。

```python
# 需要在 Dataset 中额外返回 SNR 值，然后在训练时计算权重

# Step 1：修改 DualModalDataset.__getitem__ 返回SNR
def __getitem__(self, idx):
    # ... 原有代码 ...
    if idx < self.n_hdf5:
        snr = int(self.hdf5_snrs[idx])   # ← 需要在__init__中保存SNR
    else:
        snr = int(np.random.choice(self.awgn_snrs))  # AWGN的SNR随机取
    
    # 原有的x_time, x_img, y计算...
    return x_time, x_img, torch.tensor(y, dtype=torch.long), torch.tensor(snr, dtype=torch.float)


# Step 2：定义SNR感知的加权损失
def snr_weighted_loss(criterion, logits, y, snr_vals, snr_min=-20, snr_max=30):
    """
    低SNR样本赋予更高权重。
    权重公式：w = 1 + alpha * exp(-(SNR - SNR_min) / T)
    SNR越低，权重越高（最高约为 1+alpha）。
    """
    alpha = 2.0   # 低SNR样本的最大额外权重倍数
    T     = 10.0  # 温度参数，控制权重随SNR下降的速度
    snr_norm = (snr_vals.float() - snr_min) / (snr_max - snr_min)
    weights  = 1.0 + alpha * torch.exp(-snr_norm * (snr_max - snr_min) / T)
    weights  = weights.to(logits.device)

    # 逐样本计算Loss后加权平均
    per_sample_loss = F.cross_entropy(logits, y, reduction='none')
    return (per_sample_loss * weights).mean()
```

**添加位置**：在 Cell 7 的 `DualModalDataset` 中修改 `__getitem__`，在 Cell 9 的损失计算处使用 `snr_weighted_loss`。

## 7. 证据融合：引入狄利克雷分布

这是最大幅度的结构改变，用**证据深度学习（EDL）+ Dempster-Shafer 组合规则**替换现有的 BCA 特征拼接方案。

**核心优势**：
- 低SNR时图像模态质量差 → 证据量自动趋近0 → 模型自动降低该模态权重
- 输出不确定性，可以用于论文的额外分析图（不确定性 vs SNR 曲线）

### 7.1 替换 Cell 8 的融合模块

```python
# ============================================================
# Cell 8（证据融合版）：替换 BCA + classifier 部分
# ============================================================

def relu_evidence(logits):
    """ReLU 保证证据量非负（e_k ≥ 0）。"""
    return F.relu(logits)


class EvidentialFusion(nn.Module):
    """
    基于 Dirichlet 分布 + Dempster-Shafer 的多模态证据融合。

    两个模态分别输出证据 e，转为 Dirichlet 参数 α = e + 1，
    用 DS 组合规则融合两路证据。

    优势：低SNR时图像质量差 → 图像分支证据量趋0 → 自动降权图像分支。
    """
    def __init__(self, emb_dim=256, num_classes=2, dropout=0.3):
        super().__init__()
        self.num_classes = num_classes
        self.head_time = nn.Sequential(
            nn.Linear(emb_dim, 128), nn.ReLU(), nn.Dropout(dropout),
            nn.Linear(128, num_classes)
        )
        self.head_img = nn.Sequential(
            nn.Linear(emb_dim, 128), nn.ReLU(), nn.Dropout(dropout),
            nn.Linear(128, num_classes)
        )

    def dempster_combine(self, alpha1, alpha2):
        """
        Dempster 组合规则（二分类简化版）。

        输入  alpha1, alpha2: (B, K) Dirichlet参数
        输出  alpha_fused   : (B, K) 融合后的Dirichlet参数

        冲突越大 → 融合后总证据越少 → 自动表达高不确定性
        """
        K  = alpha1.shape[-1]
        S1 = alpha1.sum(dim=1, keepdim=True)
        S2 = alpha2.sum(dim=1, keepdim=True)
        b1 = (alpha1 - 1) / S1   # 信念质量
        b2 = (alpha2 - 1) / S2
        u1 = K / S1               # 不确定性
        u2 = K / S2

        # 归一化因子（避免冲突导致分母为零）
        denom = 1 - (b1 * b2).sum(dim=1, keepdim=True)
        denom = torch.clamp(denom, min=1e-8)

        b_fused = (b1 * u2 + b2 * u1 + b1 * b2) / denom
        u_fused = (u1 * u2) / denom

        # 转回 Dirichlet 参数
        e_fused     = torch.clamp(b_fused, min=0) * K / torch.clamp(u_fused, min=1e-8)
        alpha_fused = e_fused + 1
        return alpha_fused

    def forward(self, f_time, f_img):
        e_time = relu_evidence(self.head_time(f_time))   # (B, 2)
        e_img  = relu_evidence(self.head_img(f_img))     # (B, 2)
        alpha_time   = e_time + 1
        alpha_img    = e_img  + 1
        alpha_fused  = self.dempster_combine(alpha_time, alpha_img)
        return alpha_fused, alpha_time, alpha_img


class DualBranchEvidentialNet(nn.Module):
    """
    证据融合版完整网络。
    BiLSTM + ResNet50 + ChannelAttention + EvidentialFusion
    """
    def __init__(self, emb_dim=256, num_classes=2, dropout=0.3):
        super().__init__()
        self.time_branch = BiLSTMWithAttention(4, 128, emb_dim, num_heads=4, dropout=dropout)
        self.img_branch  = ResNet50Branch(8, emb_dim, dropout, pretrained=True)
        self.fusion      = EvidentialFusion(emb_dim, num_classes, dropout)
        self.num_classes = num_classes

    def forward(self, x_time, x_img):
        f_time = self.time_branch(x_time)
        f_img  = self.img_branch(x_img)
        return self.fusion(f_time, f_img)   # 返回三个 alpha 张量
```

### 7.2 EDL 损失函数

```python
# 在 Cell 9 之前插入 EDL 损失函数定义

def edl_loss(alpha, y_true, epoch, num_classes=2, annealing_epochs=15):
    """
    证据深度学习损失 = NLL 损失 + KL 散度正则项（退火）。

    NLL 项：鼓励正确类别证据量增大
    KL  项：鼓励错误类别证据量趋0（稀疏）
    退火 ：初期 KL 权重=0，让模型先学分类，再学不确定性

    参数:
        alpha           : (B, K) Dirichlet参数
        y_true          : (B,)   真实类别
        epoch           : 当前轮次（用于退火）
        annealing_epochs: KL权重从0线性增到1的轮次数
    """
    S    = alpha.sum(dim=1, keepdim=True)
    y_oh = F.one_hot(y_true, num_classes).float()

    # NLL 项
    loss_nll = (y_oh * (torch.log(S) - torch.log(alpha))).sum(dim=1).mean()

    # KL 散度项：α̃ = y_oh + (1-y_oh)*α（错误类别压回均匀先验）
    alpha_tilde = y_oh + (1 - y_oh) * alpha
    ones        = torch.ones_like(alpha_tilde)

    kl = (torch.lgamma(alpha_tilde.sum(1)) - torch.lgamma(ones.sum(1))
          - (torch.lgamma(alpha_tilde) - torch.lgamma(ones)).sum(1)
          + ((alpha_tilde - ones) *
             (torch.digamma(alpha_tilde) -
              torch.digamma(alpha_tilde.sum(1, keepdim=True)))).sum(1)
          ).mean()

    annealing_coef = min(1.0, epoch / annealing_epochs)
    return loss_nll + annealing_coef * kl


# 修改 run_epoch 以支持证据融合
def run_epoch_edl(model, loader, optimizer, device, epoch, train=True):
    model.train() if train else model.eval()
    total_loss = total_correct = total_n = 0
    ctx = torch.enable_grad() if train else torch.no_grad()

    with ctx:
        for x_time, x_img, yb in loader:
            x_time = x_time.to(device); x_img = x_img.to(device); yb = yb.to(device)
            if train: optimizer.zero_grad()

            alpha_fused, alpha_time, alpha_img = model(x_time, x_img)

            # 主损失（融合结果）+ 辅助损失（各模态独立监督）
            loss = (edl_loss(alpha_fused, yb, epoch)
                    + 0.3 * edl_loss(alpha_time, yb, epoch)
                    + 0.3 * edl_loss(alpha_img,  yb, epoch))

            if train:
                loss.backward()
                nn.utils.clip_grad_norm_(model.parameters(), 1.0)
                optimizer.step()

            pred = alpha_fused.argmax(dim=1)
            total_correct += (pred == yb).sum().item()
            total_loss    += loss.item() * len(yb)
            total_n       += len(yb)

    return total_loss / total_n, total_correct / total_n
```

```python
# 在 Cell 11 之后插入，用于生成不确定性分析图

def predict_evidential(model, loader, device):
    """推理：返回预测、真实标签、Dirichlet参数、不确定性。"""
    model.eval()
    preds, trues, probs, uncerts = [], [], [], []
    with torch.no_grad():
        for x_time, x_img, yb in loader:
            alpha_f, _, _ = model(x_time.to(device), x_img.to(device))
            S    = alpha_f.sum(dim=1)
            prob = (alpha_f / S.unsqueeze(1)).cpu().numpy()   # 期望概率
            u    = (model.fusion.num_classes / S).cpu().numpy()  # 不确定性

            preds.extend(alpha_f.argmax(1).cpu().numpy())
            trues.extend(yb.numpy())
            probs.extend(prob)
            uncerts.extend(u)

    return (np.array(preds), np.array(trues),
            np.array(probs), np.array(uncerts))
```
