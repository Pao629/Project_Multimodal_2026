狄利克雷分布（Dirichlet Distribution）进行多模态融合的方法就是证据深度学习（Evidential Deep Learning，EDL）+ Dempster-Shafer 证据理论的多模态融合方法，非常适合你的场景。在近几年的多模态学习（尤其是不可靠模态融合、不确定性估计）领域非常火，它最典型的代表作是发表于 NeurIPS 的 **EDL（Evidential Deep Learning，证据深度学习）** 以及推广到多模态的 **TMC（Trusted Multi-view Classification）**。

对于你目前的**双模态频谱感知任务（BiLSTM 时域 + ResNet18 图像）**，答案是：**完全可以使用，而且写进论文里会是一个非常高大上的数学/学术卖点！**

下面拆解一下它的数学本质，以及为什么它特别适合你目前的频谱感知模型。

## 一、 狄利克雷分布融合的数学本质

传统的神经网络（比如你目前的模型）最后输出的是一个通过 `Softmax` 得到的概率分布（比如 $[0.8, 0.2]$，代表有 $80\%$ 的概率是信号 $H_1$）。但这种做法有一个致命缺陷：**它无法表达“不确定性（Uncertainty）”**。如果输入一段纯噪声，但由于扰动太大，ResNet 输出了 $[0.51, 0.49]$，模型只能强行判定它是信号，这就会造成虚警。

狄利克雷分布融合的核心思想是：**不让分支网络直接输出分类概率，而是输出“证据量（Evidence）” $\alpha$。**

狄利克雷分布是多项式分布的共轭先验，可以看作是“概率的概率分布”。在二分类（$H_0 / H_1$）场景下，狄利克雷分布其实就退化为了**贝塔分布（Beta Distribution）**。

### 1. 证据与不确定性

每个分支（时域分支、图像分支）都会输出一个非负的证据向量 $\boldsymbol{\alpha} = [\alpha_0, \alpha_1]$：

* $\alpha_0$：支持该样本是 $H_0$（噪声）的证据量。
* $\alpha_1$：支持该样本是 $H_1$（信号）的证据量。

总证据量 $S = \alpha_0 + \alpha_1$。此时，该模态对决策的**不确定性 $u$** 定义为：


$$u = \frac{2}{S}$$


当网络对样本感到非常困惑、给不出明显证据时，$S$ 很小，不确定性 $u$ 就会趋近于 1。

### 2. 融合机制：Dempster-Shafer (D-S) 证据理论

这正是这种方法的精妙之处。它不使用你的 `BCA`（交叉注意力）或者拼接，而是将时域分支得到的狄利克雷分布 $\text{Dir}(\boldsymbol{\alpha}_{\text{time}})$ 和 图像分支得到的 $\text{Dir}(\boldsymbol{\alpha}_{\text{img}})$，通过 **D-S 证据理论的组合公式（Dempster's Combination Rule）** 进行非线性融合。

组合公式的物理意义是：**谁的不确定性低（越自信），最终的融合决策就由谁主导；如果两个分支都表现出高不确定性，融合结果也会表现出高不确定性，而不会盲目自信。**

## 二、 你的频谱感知任务为什么要用它？（核心痛点）

引入狄利克雷证据融合，能完美解决你当前模型在通信场景下的几个痛点：

### 1. 攻克低 SNR 下的“信噪比墙”

正如你在测试集 1 中看到的，当信噪比极低（如 $-15\text{dB}$）时，时域波形已经被完全淹没，BiLSTM 分支其实是在“瞎猜”，它的不确定性 $u_{\text{time}}$ 会非常高。而此时如果图像分支（如星座图）还能隐约看出一点点调制纹理，图像分支的 $u_{\text{img}}$ 相对较低。

* **传统融合（如拼接/注意力）**：BiLSTM 的“瞎猜特征”作为噪声注入了融合层，拉低了整体表现。
* **狄利克雷融合**：D-S 理论发现 $u_{\text{time}}$ 极高，会自动**一票否决**掉时域分支的发言权，让图像分支占据绝对主导，从而把模型从“信噪比墙”的边缘拉回来。

### 2. 提供“自知之明”的动态防虚警机制

在军事无线电认知、频谱空闲检测中，**盲目自信的误判是不可接受的**。使用了狄利克雷分布后，当模型遇到极度恶劣的信道干扰时，它不会硬猜一个 $H_0$ 或 $H_1$，而是会输出一个指标：`Uncertainty = 0.95`。
在工程部署时，你可以设置：当不确定性高于 $0.3$ 时，模型直接报告“信道环境恶劣，无法判定”，从而彻底杜绝突发噪声带来的恶性虚警。

## 三、 你目前的模型如果改用它，结构该怎么变？

如果把你的代码重构成狄利克雷多模态融合架构，你的网络结构（Cell 8）会发生以下彻底的蜕变：

### 1. 去掉 BCA 和 最终分类器

原先的交叉注意力模块 `self.bca` 和最后的拼接分类器 `self.classifier` 将不再需要。

### 2. 修改双分支的输出端

让 `BiLSTMBranch` 和 `ResNet18Branch` 的最后一层全连接层直接输出 `num_classes`（即 2 维），并使用 `ReLU` 激活函数，确保输出大或等于 0。这个输出就是**证据量（Evidence）**。

### 3. 前向传播流程变更为：

1. 时域分支输出 $\text{evidence}_{\text{time}}$ $\rightarrow$ 算出 $\boldsymbol{\alpha}_{\text{time}} = \text{evidence}_{\text{time}} + 1$。
2. 图像分支输出 $\text{evidence}_{\text{img}}$ $\rightarrow$ 算出 $\boldsymbol{\alpha}_{\text{img}} = \text{evidence}_{\text{img}} + 1$。
3. 通过一个数学公式（D-S 融合算子），用 $\boldsymbol{\alpha}_{\text{time}}$ 和 $\boldsymbol{\alpha}_{\text{img}}$ 算出一个融合后的 $\boldsymbol{\alpha}_{\text{fused}}$。
4. 最终的分类期望概率为 $p_k = \alpha_k / S$。

### 4. 损失函数重构（EDL 专属损失）

不能再使用简单的 `CrossEntropyLoss` 了。为了让网络输出符合狄利克雷分布的特征，必须改用**多项式仿真损失（Multinomial Loss） + 狄利克雷散度正则项（KL Divergence Regularization）**。这个正则项的作用是：如果样本是噪声，就惩罚那些瞎编证据的分支，逼迫它们的证据量向 0 靠拢（即让不确定性向 1 靠拢）。

## 核心思想

普通 Softmax 输出的是**概率**，但不知道模型"有多确定"。
Dirichlet 分布输出的是**概率的分布**，同时给出**不确定性**：

$$p(\mathbf{p} \mid \boldsymbol{\alpha}) = \text{Dir}(\mathbf{p} \mid \boldsymbol{\alpha}) = \frac{\Gamma(\sum_k \alpha_k)}{\prod_k \Gamma(\alpha_k)} \prod_k p_k^{\alpha_k - 1}$$

其中 $\alpha_k = e_k + 1$，$e_k \geq 0$ 是神经网络输出的**证据量（evidence）**。

每个模态独立输出一组证据，然后用 **Dempster 组合规则**融合：

$$\boldsymbol{\alpha}^{\text{fused}} = \boldsymbol{\alpha}^{\text{time}} \oplus \boldsymbol{\alpha}^{\text{img}}$$

## 适合你的场景吗？

**非常适合**，原因有三：

**① 低SNR时图像模态质量差**：SNR=-20dB 时，8种模态图像几乎都是噪声图，ResNet18 输出的证据量会自动趋近于0（高不确定性），Dempster 规则会自动降低其权重，更多依赖 BiLSTM。

**② 未知调制的盲检测**：测试集2中遇到未见过的调制，模型的不确定性会升高，EDL 能明确输出"我不确定"，比强行给出一个 Softmax 概率更诚实。

**③ H0/H1 二分类**：只有两类，Dirichlet 参数只有 $\alpha_0, \alpha_1$ 两个，实现最简单。

## 如何改造你的代码

只需修改三处：**输出层、损失函数、融合方式**，BiLSTM 和 ResNet18 主体完全不变。

```python
# ============================================================
# 替换 Cell 8 中的融合部分
# ============================================================

def relu_evidence(logits):
    """将网络输出转为非负证据量（ReLU保证 e_k ≥ 0）。"""
    return F.relu(logits)


class EvidentialFusion(nn.Module):
    """
    基于 Dirichlet 分布 + Dempster-Shafer 的多模态证据融合。
    
    每个分支独立输出证据 e，转为 Dirichlet 参数 α = e + 1，
    再用 DS 组合规则融合两个模态的信念。
    """
    def __init__(self, emb_dim=256, num_classes=2, dropout=0.3):
        super().__init__()
        # 时域分支分类头（输出证据，不用Softmax）
        self.head_time = nn.Sequential(
            nn.Linear(emb_dim, 128), nn.ReLU(), nn.Dropout(dropout),
            nn.Linear(128, num_classes)       # 输出 logits → 证据
        )
        # 图像分支分类头
        self.head_img = nn.Sequential(
            nn.Linear(emb_dim, 128), nn.ReLU(), nn.Dropout(dropout),
            nn.Linear(128, num_classes)
        )

    def dempster_combine(self, alpha1, alpha2):
        """
        Dempster 组合规则（二分类简化版）。
        
        输入 alpha1, alpha2: (B, K)，Dirichlet 参数
        输出 alpha_fused   : (B, K)，融合后的 Dirichlet 参数
        
        原理：将两个独立信念源的证据合并，
        冲突越大融合后的总证据越少（自动降权）。
        """
        K = alpha1.shape[-1]
        # 转为信念质量 b_k = e_k / S，不确定性 u = K / S
        S1 = alpha1.sum(dim=1, keepdim=True)   # Dirichlet 强度
        S2 = alpha2.sum(dim=1, keepdim=True)
        b1 = (alpha1 - 1) / S1                 # 信念质量
        b2 = (alpha2 - 1) / S2
        u1 = K / S1                             # 不确定性
        u2 = K / S2

        # Dempster 归一化因子（冲突项）
        # C = sum_{i≠j} b1_i * b2_j
        C = 1 - (b1 * b2).sum(dim=1, keepdim=True) \
              - b1 * u2 - b2 * u1               # 近似冲突
        C = torch.clamp(C, min=1e-8)

        # 融合信念
        b_fused = (b1 * b2 + b1 * u2 + b2 * u1) / C
        u_fused = (u1 * u2) / C

        # 转回 Dirichlet 参数
        e_fused = torch.clamp(b_fused, min=0) * (K / torch.clamp(u_fused, min=1e-8))
        alpha_fused = e_fused + 1
        return alpha_fused

    def forward(self, f_time, f_img):
        # 各模态独立输出证据
        e_time = relu_evidence(self.head_time(f_time))   # (B, 2)
        e_img  = relu_evidence(self.head_img(f_img))     # (B, 2)

        # Dirichlet 参数 α = e + 1
        alpha_time = e_time + 1
        alpha_img  = e_img  + 1

        # Dempster 融合
        alpha_fused = self.dempster_combine(alpha_time, alpha_img)

        return alpha_fused, alpha_time, alpha_img   # 返回融合+各模态（用于损失计算）


class DualBranchEvidentialNet(nn.Module):
    """用证据融合替换原来的 BCA+拼接方案，其余结构完全不变。"""
    def __init__(self, emb_dim=256, num_classes=2, dropout=0.3):
        super().__init__()
        self.time_branch = BiLSTMBranch(4, 128, emb_dim, dropout)
        self.img_branch  = ResNet18Branch(8, emb_dim, dropout, pretrained=True)
        self.fusion      = EvidentialFusion(emb_dim, num_classes, dropout)
        self.num_classes = num_classes

    def forward(self, x_time, x_img):
        f_time = self.time_branch(x_time)
        f_img  = self.img_branch(x_img)
        return self.fusion(f_time, f_img)   # (alpha_fused, alpha_time, alpha_img)
```

## 损失函数（EDL Loss）

这是与普通 CrossEntropy 最大的区别，需要替换：

```python
def edl_loss(alpha, y_true, epoch, num_classes=2, annealing_epochs=10):
    """
    证据深度学习损失 = NLL 损失 + KL 正则项（退火权重）。
    
    NLL 项：鼓励正确类别的证据量增大
    KL 项 ：鼓励错误类别的证据量趋近于0（稀疏证据）
    退火  ：训练初期 KL 权重小，让模型先学会分类，再学会不确定性
    
    参数:
        alpha          : (B, K) Dirichlet 参数
        y_true         : (B,)   真实类别标签
        epoch          : 当前训练轮次（用于KL退火）
        annealing_epochs: KL权重从0线性增长到1所需的epoch数
    """
    S   = alpha.sum(dim=1, keepdim=True)          # Dirichlet 强度
    p   = alpha / S                               # 期望概率

    # ── NLL 损失（类似交叉熵，但基于 Dirichlet 期望）────────
    y_oh  = F.one_hot(y_true, num_classes).float()
    loss_nll = (y_oh * (torch.log(S) - torch.log(alpha))).sum(dim=1).mean()

    # ── KL 散度正则项（压制错误类别的证据）──────────────────
    # 将错误类别的证据置0，只保留正确类别
    alpha_tilde = y_oh + (1 - y_oh) * alpha      # 错误类别 α̃=1（均匀先验）
    ones = torch.ones_like(alpha_tilde)

    lgamma_sum  = torch.lgamma(alpha_tilde.sum(dim=1))
    lgamma_ones = torch.lgamma(ones.sum(dim=1))
    lgamma_k    = torch.lgamma(alpha_tilde) - torch.lgamma(ones)

    kl = (lgamma_sum - lgamma_ones
          - lgamma_k.sum(dim=1)
          + ((alpha_tilde - ones) *
             (torch.digamma(alpha_tilde) -
              torch.digamma(alpha_tilde.sum(dim=1, keepdim=True)))).sum(dim=1)
          ).mean()

    # ── KL 退火权重（线性从0增长到1）────────────────────────
    annealing_coef = min(1.0, epoch / annealing_epochs)

    return loss_nll + annealing_coef * kl


# 训练循环中的损失计算修改：
def run_epoch_edl(model, loader, optimizer, device, epoch, train=True):
    model.train() if train else model.eval()
    total_loss = total_correct = total_n = 0
    ctx = torch.enable_grad() if train else torch.no_grad()

    with ctx:
        for x_time, x_img, yb in loader:
            x_time = x_time.to(device); x_img = x_img.to(device); yb = yb.to(device)
            if train: optimizer.zero_grad()

            alpha_fused, alpha_time, alpha_img = model(x_time, x_img)

            # 主损失：融合证据的EDL损失
            loss_fused = edl_loss(alpha_fused, yb, epoch)
            # 辅助损失：各模态独立监督（让每个分支也能单独工作）
            loss_time  = edl_loss(alpha_time, yb, epoch)
            loss_img   = edl_loss(alpha_img,  yb, epoch)
            # 总损失：融合为主，各模态辅助
            loss = loss_fused + 0.3 * loss_time + 0.3 * loss_img

            if train:
                loss.backward()
                nn.utils.clip_grad_norm_(model.parameters(), 1.0)
                optimizer.step()

            # 用融合 alpha 的期望概率计算准确率
            pred = alpha_fused.argmax(dim=1)
            total_correct += (pred == yb).sum().item()
            total_loss    += loss.item() * len(yb)
            total_n       += len(yb)

    return total_loss / total_n, total_correct / total_n
```
